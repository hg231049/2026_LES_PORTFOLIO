01 — 기본 배경

왜 이 작업이 필요했나

배경 01

검색 성과 정체 / 하락

브랜드 인지도·제품 경쟁력·광고 유입 트래픽은 충분히 확보된 상태였지만, 자연 검색(SEO) 관점에서는 성과가 정체 또는 하락하는 현상 발생

  • 경쟁사 대비 동일 키워드 노출 순위 열세
  • 광고 제외 시 3번째 순서 이후 또는 다음 페이지 노출
  • 콘텐츠 부족이 아닌 구조 인식 오류 신호
배경 02

아임웹 기반 구조 한계 + 퍼블리싱 누적 이슈

  • 위젯 중심 구조
  • JS 렌더링 비중이 높은 화면 구성
  • 메인/카테고리/상세 페이지 경계 모호
  • H1·시맨틱 구조 불명확
  • 메타태그 존재하나 페이지별 역할 신호 약함
  • 이미지 alt 태그 누락, 이미지 용량 문제, 중복 코드
배경 03

Core Web Vitals 이슈로 SEO 평가 하락

띠배너 타이머, GIF 이미지, 스크립트 기반 콘텐츠 삽입 등으로 레이아웃 이동 반복 발생

  • 레이아웃 불안정 (CLS 악화)
  • 사용자 경험 저하 → 이탈률 상승
  • SEO 점수 및 페이지 품질 평가 하락
배경 04

메타태그 신호 재정비 필요

  • 메인/카테고리/상세 간 메타 title·description 역할 구분 불명확
  • 특정 키워드 검색 시 의도치 않은 페이지(메인)가 노출
  • 카테고리 페이지 검색 결과 미노출 문제
  • 중복 title·모호한 description → 감점 요인
02 — 주요 작업

SEO · 퍼블리싱 개선 작업 내용

01
이미지 접근성 및 SEO 신호 개선
상품 목록·상세 페이지 이미지에 상품명 기반 alt 태그 자동 삽입 로직 구현. JS 렌더링 구조에서도 검색엔진이 이미지 의미를 인식할 수 있도록 보완.
alt 태그 자동화 JS 렌더링 대응 이미지 SEO
02
모바일 UI/UX 기반 성능 최적화
모바일 퀵메뉴·플로팅 배너·띠배너(타이머) 영역에서 발생하던 레이아웃 이동 이슈 분석 및 고정 레이아웃 처리. aspect-ratio, min-height 기반 레이아웃 설계로 반응형 환경에서도 CLS 미발생.
CLS 개선 aspect-ratio min-height 반응형
03
Core Web Vitals 개선 (CLS / LCP)
메인 비주얼(Swiper) 영역의 초기 높이 미확정으로 발생하던 CLS 문제 해결 → CLS 0.47에서 안정 수준으로 개선. LCP 대상 요소를 메인 히어로 이미지/영상으로 명확화. lazyload 적용 범위 재조정으로 초기 렌더 안정성 확보.
CLS 0.47 → 안정 LCP 명확화 lazyload 재조정
04
검색엔진 이해도 높이는 구조 개선
메인 페이지에 시맨틱 태그(header / main / section / footer) 기반 구조 적용. 페이지별 H1 구조 정리(sr-only 포함)로 검색엔진 주제 인식 강화. 메타 title/description 중복 구조 점검 및 페이지 단위 정상 동작 보장.
시맨틱 HTML H1 구조화 메타태그 정비 sr-only

04 — 메타태그 개선

메타태그 수정의 핵심 목적과 기대 효과

핵심 목적

  • 각 페이지가 역할을 분담하도록 신호 분리
    메인(브랜드 허브) / 카테고리(탐색) / 상세(구매)
  • 동일 순위에서 사용자가 클릭할 이유 명확화
    광고 문구 ❌ → 페이지 정보 요약형 문장 ⭕
  • 중복 title 제거 / description 누락 방지
  • 페이지별 고유 메타 정보 보장

단기 기대 효과

  • 크롤링 시 페이지 주제 인식 명확화
  • SEO 점수 툴 기준 메타 경고 항목 감소
  • 검색 결과에서 잘못된 페이지 노출 빈도 감소

중장기 기대 효과

  • 카테고리/상세 페이지 검색 쿼리 매칭 정확도 향상
  • CTR 개선 → 사용자 반응 데이터 축적
  • Core Web Vitals 개선과 결합 시 자연 검색 유입 회복 기반 마련

개선 작업 요약

  • 메타 타이틀 페이지별 수정
  • 메타 설명(description) 개선
  • 콘텐츠 구조 개선 (시맨틱 태그)
  • 내부 링크 증가
  • 이미지 alt 태그 삽입
  • 페이지 로딩 성능 개선
